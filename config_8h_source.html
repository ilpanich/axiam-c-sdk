39/* --- Local token-verification expectations (§10.1 rules 5 and 6). ---
40 *
41 * Both are OPTIONAL and default to UNSET. When unset, the corresponding claim
42 * is not checked by axiam_jwt_verify(); when set, a token whose claim is
43 * absent, of the wrong JSON type, or different MUST be rejected. Passing NULL
44 * or "" clears the expectation. The SDK never assumes an issuer or audience.
45 *
46 * A resource server guarding a user-facing API SHOULD set the audience to
47 * "axiam:user". The issuer is deployment-specific (typically the AXIAM base
48 * URL) and is therefore never defaulted.
