Detailed Description

One network.segments[] entry (CONTRACT.md §27.6.2 item 1, contract 1.62).

The natural key is site + kind + name, where kind is the WIRE spelling, access or quarantine, exactly the value create_segment writes and every read returns. There is no zones spelling anywhere in a manifest: that is a server-side path segment. site, kind and name are the key and are never drift (§36.3 rule 4); every other member is a field.

const char* const* axiam_mgmt_network_segment_spec::filter_ids

The segment's envelope, in the order the manifest states it, or NULL for silent.

COMPARED AS A SET (names are exact strings; a reorder alone is NoChange), and SENT in this order. A name listed twice is refused at plan with zero wire calls. A non-NULL pointer with filter_ids_count 0 states an EMPTY envelope.
