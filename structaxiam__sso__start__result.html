Detailed Description

POST /api/v1/auth/federation/oidc/start (§12.1) — where to send the user agent for upstream-IdP federation, and the single-use state tying the callback to it.

There is no nonce here: the server keeps the federation nonce server-side (§12.1 note 7), so an SDK has nothing to check.
