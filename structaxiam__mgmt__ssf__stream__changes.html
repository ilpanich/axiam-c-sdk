Detailed Description

The changes axiam_mgmt_ssf_stream_apply_changes() applies over a stream that was read.

A member left NULL (or with its has_ flag 0) is unchanged: the read's value goes back. Every string is borrowed for the call. Zero-initialise it (= {0}) and set what you change. To drop an optional member (description, endpoint_url, status_reason), edit the result: free the member and set it NULL.
