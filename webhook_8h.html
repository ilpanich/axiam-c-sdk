◆ axiam_webhook_status

enum axiam_webhook_status

Outcome of a webhook verification.

Anything other than AXIAM_WEBHOOK_OK means the delivery MUST be rejected.

Enumerator
AXIAM_WEBHOOK_OK 

Signature valid and fresh.

AXIAM_WEBHOOK_ERR_INVALID_ARGUMENT 

NULL secret/header/body pairing.

AXIAM_WEBHOOK_ERR_MALFORMED_SIGNATURE 

No/duplicate t, no v1, non-numeric t, or a timestamp header disagreeing with t.

AXIAM_WEBHOOK_ERR_SIGNATURE_MISMATCH 

No supplied v1 matched.

AXIAM_WEBHOOK_ERR_STALE_TIMESTAMP 

|now - t| exceeded the tolerance.

AXIAM_WEBHOOK_ERR_INTERNAL 

HMAC/allocation failure.

Verify an X-Axiam-Signature header against the raw body.

Parameters
secretthe webhook's plaintext secret, behind Sensitive (§7).
signature_headerthe raw X-Axiam-Signature value.
bodyraw request body bytes (may be NULL only when body_len is 0).
body_lenlength of body in bytes.
tolerance_secsfreshness window; <= 0 selects AXIAM_WEBHOOK_DEFAULT_TOLERANCE_SECS.
out_timestampoptional; receives the verified t on success.
Returns
AXIAM_WEBHOOK_OK, or a typed failure.

axiam_webhook_status_t axiam_webhook_verify_headers ( const axiam_sensitive_t *  secret,

const void *  body,

long  tolerance_secs,
axiam_webhook_event_t *  out_event

Verify a delivery from its full header list, and on success populate out_event with the event type, delivery id (dedup key) and body copy.

Requires X-Axiam-Signature. When X-Axiam-Timestamp is also present it MUST equal the t= field, else the delivery is refused as malformed. out_event may be NULL if only the verdict is wanted.
