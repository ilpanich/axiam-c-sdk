Detailed Description

A TOTP factor offered but not yet active (§25.1).

BOTH HALVES ARE SENSITIVE, AND THE SECOND ONE IS WHY. The otpauth:// URI CONTAINS the secret: wrapping the bare secret and leaving the URI as a plain string has wrapped nothing, because the URI is the field that actually gets logged — it is the one the caller passes to a QR renderer (§25.3).
