Detailed Description

What axiam_mgmt_plan produced: the ordered changes an apply would make.

Includes the UNCHANGED entries as well, so a reader sees what was considered and not only what moved. bindings is a SEPARATE ordered list (role bindings are relationships between two entities, not entities themselves — see axiam_mgmt_apply()'s doc comment for exactly where each bindings entry runs relative to changes).
