◆ button_icon

char* axiam_mgmt_create_federation_config_request::button_icon

Sign-in-button icon for a generic provider, as a base64 raster data URL (data:image/png;base64,…), already cropped to PROVIDER_ICON_SIZE_PX square by the client.

Refused for the branded kinds: Google, Apple and Microsoft all publish sign-in-button rules that require their own mark, so substituting a picture would produce a button that breaks the guidelines it exists to follow. Optional.
