1/*
2 * AXIAM C SDK — Telemetry hooks (CONTRACT.md §19).
3 *
4 * An optional callback surface so a caller can wire OpenTelemetry, Prometheus
5 * or a log line WITHOUT this library depending on any of them. Install one with
6 * axiam_client_config_set_telemetry_hook(); with none installed the cost is a
7 * single NULL check per request.
8 *
9 * Two of §19.2's rules are enforced by the shape of this header rather than
10 * left to documentation:
11 *
12 * - No secrets, ever (§19.2 rule 3). The event is a fixed struct with a fixed
13 * field list and NO free-form map or body pointer. There is nowhere to put
14 * a token in a payload bound for a metrics backend — the type, not a review
15 * comment, is what keeps them out.
16 * - No cost when uninstalled (§19.2 rule 1). Every field is a borrowed
17 * pointer or a scalar; nothing is allocated to build an event.
18 *
19 * LIFETIME: every `const char *` in an event borrows storage owned by the SDK
20 * and valid only for the duration of the hook call. A hook that needs to keep a
21 * string MUST copy it. Every pointer is either NULL or NUL-terminated; a field
22 * not carried by the event's kind is NULL (or 0).
23 *
24 * THREADING: the hook is invoked on the calling thread, inside the operation
25 * that produced the event, and MUST NOT block (§19.2 rule 4). Buffering is the
26 * caller's job so they can pick the policy; every mature metrics library
27 * already buffers.
28 */
