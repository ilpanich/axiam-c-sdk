Detailed Description

The validated claims of an ID token (§12.4).

Present on a token set only when the response carried an id_token AND every §12.4 rule passed.

◆ raw_claims_json

char* axiam_id_token_claims::raw_claims_json

The complete claim set as JSON, verbatim.

§12.1 requires SDKs to PRESERVE claims beyond the named ones and forbids rejecting unknown ones — the ID token's full claim set is not enumerated by openapi.json. In a language with an open map this is a dictionary member; in C it is the raw object, which a caller parses with whatever JSON library it already has.
