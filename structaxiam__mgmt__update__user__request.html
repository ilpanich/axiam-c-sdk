Detailed Description

The UpdateUserRequest schema from the server's OpenAPI document.

Every member is optional, so this is a SPARSE body (27.4 rule 5): a NULL pointer – or a has_ flag left 0 – means the field is OMITTED from the request entirely, not sent as null. On a sparse update those say opposite things, and only omission means "leave it alone".
