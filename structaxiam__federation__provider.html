Detailed Description

One sign-in button, from GET /api/v1/auth/federation/providers (§12.1).

Carries what a button needs and nothing else: there is no client_id, no metadata_url, no endpoint URL and no secret in this shape. The server builds it as a dedicated unauthenticated response rather than narrowing the admin one, so a field added to the admin response cannot reach here by inheritance.

OidcConnect, Saml or OAuth2 — selects the start operation (note 10).

Deliberately the wire string and not an enum: the server may add a protocol, and a closed enum would fail the parse of the whole list over one provider this build predates. Compare against the three AXIAM_FEDERATION_PROTOCOL_* macros and treat anything else as "cannot start this one here".
