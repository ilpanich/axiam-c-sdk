Detailed Description

What a plan intends to do to one network object (CONTRACT.md §27.6.2 item 3).

The read the decision was made on is kept, because an Update's body is BUILT FROM IT (item 4): every stated member replaces the read's and every unstated one is carried, with the version the plan read. All of the pointers are owned by the plan.

char* axiam_mgmt_planned_network::applied_segment_id

Filled by axiam_mgmt_apply on a SEGMENT item that wrote: the id and the version of the WRITE'S RESPONSE, which is what a profile that follows sends as segment_version (the segment write moved it; the one plan read would be 409 stale_version).
