◆ uma_registered_by

char* axiam_mgmt_resource::uma_registered_by

The client_id that registered this resource through the UMA Protection API (X2), or None for a resource created any other way.

Read-only from every ordinary path: [UpdateResource] cannot set it and [CreateResource] cannot either, so the only writer is the resource-registration handler. That is deliberate — the field backs a provenance badge in the admin UI, and a provenance marker anyone can write is decoration that reads like evidence. Optional.
