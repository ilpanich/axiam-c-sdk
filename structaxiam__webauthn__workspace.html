Detailed Description

The workspace a usernameless ceremony runs in (§24.1).

discoverable/start is the one WebAuthn endpoint that carries the workspace explicitly, because a usernameless ceremony has no prior step to have minted a token that names it. Unlike the five /oauth2 operations of §12.1 rule 2 it ACCEPTS SLUGS, so a slug-only client can run it.

Pass NULL to axiam_webauthn_discoverable_start() to have it filled from the client's own configured identity, which is what almost every caller wants. Every member is borrowed, not owned: nothing here is freed by this SDK.
